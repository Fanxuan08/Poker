# Poker Game (五張撲克牌遊戲)

## 專案簡介

本專案為一個結合下注機制與經典五張撲克牌遊戲。
除了基礎的洗牌、發牌與牌型判定功能，亦針對玩家的遊戲操作體驗、防呆機制與介面視覺進行了進階的設計與擴充。

### 基礎功能

* **經典撲克牌玩法**
  * 使用標準 52 張撲克牌進行遊戲。具備完整的洗牌機制 (Shuffle)、發牌、換牌，並動態生成與管理 5 張撲克牌物件。
* **動態牌型判定與賠率計算**
  * 系統能自動分析玩家最終的五張牌面，精準判定從「一對」、「兩對」、「順子」到最高階的「皇家同花順」等各階級牌型。
  * 依據對應的牌型賠率自動計算獎金（例如：皇家同花順 250 倍、同花順 50 倍、兩對 2 倍等）。
* **資金與下注管理**
  * 遊戲初始提供 1,000,000 元作為總資金，並記錄當局押注金額。計算結算後，會自動將贏得的獎金加總回總資金中。

### 進階創意擴充

* **互動式視覺換牌**
  * 玩家可直接以滑鼠點擊畫面上的撲克牌進行「保留」或「更換」的選擇。點選後，牌面會即時翻轉為背面（覆蓋狀態），直觀地向玩家呈現即將被換掉的牌。
* **嚴謹的狀態控制與防呆機制**
  * **按鈕狀態鎖定**：根據遊戲進程（下注 ➔ 發牌 ➔ 換牌 ➔ 結算），系統會動態啟用或禁用對應的按鈕與輸入框。例如：下注後即鎖定金額修改、未發牌前無法換牌，防止玩家誤觸導致邏輯崩潰。
  * **數值驗證**：押注金額內建輸入防呆，確保數值必須為大於零且不超過當前總資金的有效數字。
* **無滑鼠下注快捷操作**
  * 在「押注金額」輸入框中綁定了 `Enter` 鍵快捷事件。玩家輸入完金額後只需按下 `Enter` 即可一鍵送出下注，系統並會自動消除 Windows 預設的警告提示音，提升操作流暢度。
* **客製化介面視覺 (自訂繪圖)**
  * 透過覆寫 `GroupBox` 的 `Paint` 事件，手動清除系統預設的制式邊框，並重新繪製標題文字。此舉打破了傳統 Windows Form 的生硬邊框限制，打造出更乾淨、沉浸的遊戲桌面視覺。

# 執行說明

## 系統操作說明 (使用者視角)

### 1. 遊戲初始與下注防呆
* **數值輸入**：遊戲開始時，畫面會呈現五張蓋著的撲克牌。玩家需於「押注金額」欄位輸入欲下注的數字，點擊「押注」按鈕（或直接按下鍵盤 `Enter` 鍵）。
  
  <img width="500" height="329" alt="螢幕擷取畫面 2026-05-06 161436" src="https://github.com/user-attachments/assets/6deec567-53e4-4068-8662-46739a3c2af4" />

* **錯誤攔截**：若玩家輸入非數字字元、空白，或是輸入的金額「小於等於零」或「大於當前總資金」，系統將中斷動作並跳出警告視窗提示「請輸入正確的數字格式！」或「押注金額無效或資金不足！」。

  <img width="400" height="159" alt="merged-image-2026-" src="https://github.com/user-attachments/assets/3daeed1b-74d9-4910-b0d8-3446001c9cf7" />

### 2. 遊戲主流程 (發牌與換牌)
* **發牌**：下注成功後，押注區將被鎖定。點擊「發牌」按鈕，系統會隨機發出五張明牌。
  
  <img width="500" height="327" alt="螢幕擷取畫面 2026-05-06 163204" src="https://github.com/user-attachments/assets/829d306e-7a81-456b-8f97-670b919b77a9" />

* **選擇換牌**：玩家可單擊不想保留的撲克牌，該牌會立刻翻面顯示為「牌背」，表示待換。選定完畢後，點擊「換牌」按鈕，系統會針對呈現牌背的位置重新發放新牌，並鎖定所有卡牌的點擊功能。

  <img width="1000" height="327" alt="merged-image-2026- (1)" src="https://github.com/user-attachments/assets/4ffa9838-e858-4f9c-8361-7ac3295a73f2" />


### 3. 牌型結算與獎金發放
* 換牌完成後，點擊「判斷牌型」按鈕，系統會立即分析最終的五張牌面。
* 判定結果與贏得的獎金將清晰顯示於介面右下方（如圖示中的「2,A兩對！贏得 1000 元!!!」），並自動將獎金匯入左側的「總資金」內。
* 結算完成後，系統會自動重置按鈕狀態，重新開放「押注金額」欄位，讓玩家可以順暢地進行下一局遊戲。
